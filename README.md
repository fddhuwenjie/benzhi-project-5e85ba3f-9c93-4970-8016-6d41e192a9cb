# 风洞试验安全放行台

风洞试验安全放行台是面向空气动力试验团队的单机浏览器工作台。它把一次试验从任务建档、运行边界评估、测量通道校准、联锁演练、独立见证整改推进到最终授权和证据封存串成唯一状态机；缺少安全证据时，档案不会进入可执行状态。服务使用本地 SQLite 保存修订链、幂等请求和审计事件，证据包以确定性 JSON 和 SHA-256 摘要导出。

工作台在建档和维护时提供字段预检、在途档案查重与 revision 差异确认；运行边界支持不落库试算和方案量程影响对比，测量通道支持批量原子核验及动态校准回退，联锁演练保留按类型的失败复演历史。见证整改采用负责人提交、原见证员核销或重开的双人职责，授权前展示固定清单摘要。审计时间线支持角色、操作者、revision 和时间范围组合筛选，并返回全量阶段统计。

## 构建、运行和测试

需要 Go 1.23 或更高版本。标准构建命令：

```text
go build ./cmd/server
```

直接运行服务（默认仅监听高位回环地址 `127.0.0.1:19081`）：

```text
go run ./cmd/server
```

可以用 `-addr=127.0.0.1:<port>` 指定监听地址，也可以设置 `PORT` 端口号；服务只接受 `127.0.0.1`，不会默认绑定公网地址。默认数据库文件为工作区内的 `windtunnel.db`，可用 `-db` 指定路径。

运行完整测试和真实 HTTP 自检：

```text
go test ./...
go run ./cmd/server -selfcheck -addr=127.0.0.1:19081
```

浏览器打开 `http://127.0.0.1:19081/`，即可使用原生 HTML、CSS 和 JavaScript 工作台。
